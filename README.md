# PGFB KPI

Pagina statica pubblica che descrive come vengono calcolati i KPI e i premi
mensili di Il Mannarino.

Il sito viene pubblicato su dominio personalizzato direttamente dalla root del branch
`main`:

```text
https://kpi.ilmannarino.it
```

## Provenienza

Il repository preserva la cronologia del sito originariamente pubblicato da
`IlMannarinoA/kpi`. La migrazione sotto l'organizzazione PGFB elimina la
dipendenza operativa da un account personale.

## Sviluppo locale

Servire la directory con un qualunque server HTTP statico e aprire
`index.html`. Il sito non richiede build, dipendenze JavaScript o backend.
